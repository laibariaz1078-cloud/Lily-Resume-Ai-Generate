# Lily Studio

A frontend-only resume studio prototype built with Next.js, React, Tailwind CSS, Framer Motion, and Lucide icons.

```bash
npm install
npm run dev
```

The public site is available at `/`. The workspace includes `/dashboard`, `/builder`, `/resumes`, `/favorites`, `/workspace/templates`, `/ai-assistant`, `/subscription`, `/profile`, and `/settings`. Public information and demo account screens are available at `/features`, `/templates`, `/about`, `/testimonials`, `/contact`, `/pricing`, `/login`, `/signup`, and `/forgot-password`.

All account, AI, and payment interactions are mock experiences. Resume content is saved in browser storage. The AI writing helper uses local rules and does not call a server or external AI service. Use the builder's Export PDF button and choose Save as PDF in the browser print dialog.
